## Corrections to the audit
- **M10** was partly already fixed live: `supabase/rls-anon-write-lockdown.sql` (unversioned) removed anon insert and revoked anon writes; what remained was `authenticated` insert (any self-signed-up user). 0055 closes that and brings it into versioned migrations.
- **M11** receipts: `0043` already closes the any-authenticated hole (stated in the audit's follow-up).
- **invoice_counters** has RLS enabled with zero policies per the lockdown file's own notes; 0055 deliberately does not touch it.

## Intentionally left (and why)
- **H1, CRM service-role key on the public site.** Removing it needs a CRM-side change (webhook endpoints for `unsubscribe`, `owner-report`, `tracking-retention`, `market-report`, or a scoped Postgres role + JWT) that doesn't exist yet; swapping it blind would break unsubscribes, owner-report tracking and the market-report cron. Blast radius is limited to those server routes (the key is never in client code). Recommended next step: add a narrow CRM webhook per route, then rotate the key. `unsubscribe/route.ts` also falls back to the main service-role key if `CRM_SUPABASE_SERVICE_ROLE_KEY` is unset; left as is to avoid breaking a working config.
- **M4 reCAPTCHA fail-open** on `/api/leads`: deliberate trade-off documented in code (an ad-blocker shouldn't cost a genuine lead). Onboard already fails closed.
- **M5** per-recipient send cap and fixed greeting: changes the confirmation email copy / needs a new table; the durable limiter plus CR/LF stripping reduce the abuse. Open to doing it as a follow-up.
- **M6 nonce-based CSP:** requires dynamic rendering of every page (kills the static/ISR pages), a large behavior and performance change. `'unsafe-inline'` remains; no raw-HTML sink with user data exists.
- **Nested `postcss` advisory:** only fixed by Next 16.
- **`/client/[token]` expiry, pre-change invoice tokens' non-expiry:** would break links already in clients' inboxes. Rotate individually via the existing rotate-portal-token route.
- **Local-machine items:** `.env.local.bak` (secrets copy, untracked), `.mcp.json` project ref, `deploy.sh` laptop deploys. Not touched; Zack should delete the `.bak` himself.
- **Privacy/consent copy, `subscribe/confirmed` constant `innerHTML`:** not security-impacting today.
